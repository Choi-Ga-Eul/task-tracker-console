# Task Tracker
## 1. Task Tracker Overview
Task Tracker는 해야 할 일을 등록하고, 완료 여부와 진행 상황을 확인할 수 있는 Java Console 기반 프로그램이다. 할 일마다 제목과 우선순위를 지정하고, 목록 조회·완료 처리·삭제·진행 통계를 통해 작업을 관리한다.

할 일은 최대 20개까지 관리할 수 있다. 데이터는 프로그램 실행 중 메모리에만 유지되며, 종료하면 모두 삭제된다. 재실행 시에는 빈 목록으로 시작한다.

## 2. Task Tracker Features

| 기능 ID | 기능명            | 설명                                                                                                         |
|---------|-------------------|--------------------------------------------------------------------------------------------------------------|
| F01     | 메뉴              | 메뉴를 반복해서 출력하고, 유효한 번호를 입력받아 해당 기능을 실행한다. `0`을 선택하면 프로그램을 종료한다.   |
| F02     | 할 일 등록        | 제목과 우선순위를 입력받아 미완료 상태의 할 일을 등록한다. 최대 20개까지 등록할 수 있다.                     |
| F03     | 할 일 전체 조회   | 등록된 모든 할 일을 등록 순서대로 조회한다.                                                                  |
| F04     | 완료 할 일 조회   | 완료 상태인 할 일만 등록 순서대로 조회한다.                                                                  |
| F05     | 미완료 할 일 조회 | 미완료 상태인 할 일만 등록 순서대로 조회한다.                                                                |
| F06     | 할 일 완료 처리   | 선택한 미완료 할 일을 완료 상태로 변경한다. 이미 완료된 항목을 선택하면 안내문을 출력하고 메뉴로 돌아간다.   |
| F07     | 할 일 미완료 처리 | 선택한 완료 할 일을 미완료 상태로 변경한다. 이미 미완료인 항목을 선택하면 안내문을 출력하고 메뉴로 돌아간다. |
| F08     | 할 일 삭제        | 선택한 할 일을 삭제한다. 삭제된 항목 뒤에 있는 할 일의 번호는 1씩 줄어든다.                                  |
| F09     | 할 일 진행 통계   | 전체·완료·미완료 할 일 수와 완료율을 확인한다. 할 일이 없으면 통계값 대신 안내문을 출력하고 메뉴로 돌아간다. |

### 메뉴 구성

| 번호 | 기능              |
|------|-------------------|
| 0    | 종료              |
| 1    | 할 일 등록        |
| 2    | 할 일 전체 조회   |
| 3    | 완료 할 일 조회   |
| 4    | 미완료 할 일 조회 |
| 5    | 할 일 완료 처리   |
| 6    | 할 일 미완료 처리 |
| 7    | 할 일 삭제        |
| 8    | 할 일 진행 통계   |


### 등록 규칙
- 제목 길이는 trim() 적용 후 Java의 String.length() 반환값을 기준으로 1~30이어야 한다. 같은 제목을 중복 등록할 수 있다.
- 우선순위는 1: 높음, 2: 보통, 3: 낮음으로 구분한다.
- 새로 등록한 할 일은 미완료 상태로 시작한다.
- 이미 20개가 등록되어 있으면 제목과 우선순위를 입력받지 않고, 등록을 거부한 뒤 메뉴로 돌아간다.
  
### 번호 선택 및 입력 규칙
- 할 일 번호는 현재 목록의 인덱스 + 1이며, 영구 식별자가 아니다.
- 현재 목록에 존재하는 번호만 선택할 수 있다. 예를 들어 할 일이 3개이면 유효한 번호는 1~3이다.
- 목록이 비어 있으면 번호를 입력받지 않고, 안내문을 출력한 뒤 메뉴로 돌아간다.
- 숫자는 한 줄에 정수 하나만 입력하며, 앞뒤 공백은 허용한다.
- 잘못된 입력은 데이터를 변경하지 않고 해당 입력을 다시 받는다.
  
### 진행 통계

| 항목            | 기준                                                               |
|-----------------|--------------------------------------------------------------------|
| 전체 할 일 수   | 현재 목록에 등록된 할 일 개수                                      |
| 완료 할 일 수   | 완료 상태인 할 일 개수                                             |
| 미완료 할 일 수 | 미완료 상태인 할 일 개수                                           |
| 할 일 완료율    | `완료 개수 × 100.0 / 전체 개수`로 계산하고 소수점 한 자리까지 표시 |


전체 할 일 수가 0이면 완료율을 계산하지 않으며, 통계값 없이 안내문을 출력하고 메뉴로 돌아간다.

## 4. Getting Started Task Tracker
### 4-1. Installation
```shell
git clone https://github.com/Choi-Ga-Eul/task-tracker-console.git
```

### 4-2. Build
```shell
javac -encoding UTF-8 -d out src/TaskTracker.java
```
### 4-3. Run
```shell
java -cp out TaskTracker
```
